Chrome 扩展 · Manifest V3 · 配合原生垂直标签栏

它不替你排列标签，
它替你判断标签

Chrome 145+ 已经原生支持垂直标签栏，纵向列表和标签组浏览器自己做得更好。Sift 不跟它抢渲染层，只做原生没有的那一半：这些标签是什么、哪些在摸鱼、哪些又重又没人看、该关掉哪些最划算、关掉的东西去哪儿找回来。

sift — AI 标签管家

浏览器负责渲染，Sift 负责判断

重合的部分交给原生，剩下的才是它该干的。

✦

AI 语义分组

接入 DeepSeek / OpenAI 兼容端点按语义归组。规则先行、缓存复用，只有没见过的标签才送给 AI，省 token 也更快。

◆

可对话的标签助手

「哪些标签在摸鱼」「总结我正在看的页面」「恢复我刚关掉的」——问答与操作一体，改动类操作一律先预览再确认。

⧉

原生标签组同步

分组结果直接写进 Chrome 原生标签组，含颜色与折叠状态。整理效果就在浏览器自己的标签栏里，不画第二份列表。

▣

归档抽屉

标签囤积的根因不是没整理，是「关掉就找不回来」。归档让关闭这件事不再需要勇气，随时可搜索、批量恢复、导出 Markdown。

⌫

智能清理

AI 逐个判断哪些可以清理并给出理由，默认动作是归档而不是关闭——判断错了也不会真的丢东西。

⚡

标签性能账单

实测每个标签的 JS 堆、DOM 节点与图片位图，算出重量分与浪费分。不扫描时常驻开销为 0，扫完还能交给 AI 给关闭建议。

⌘

快捷键召唤

面板不常驻，任意页面一个快捷键唤起。常驻挂件有个死结：低调到不烦人，就一定低调到看不见。

☾

休眠与自动归档

闲置标签自动挂起省内存；超过设定天数没访问的自动收进归档并关闭——休眠只省内存，归档才省注意力。

⤳

来源链路

记录每个标签是从哪儿点开的，串成树。顺着一条链看完，也能整条关掉。

AI 智能分组

一键让标签各归各位

点一下，Sift 调用你配置的大模型，按语义把「工作文档」「社交媒体」「技术资料」分门别类，并同步成 Chrome 原生标签组——所以整理结果直接呈现在浏览器自己的标签栏里。自定义规则命中的标签完全不发给 AI，既省 token，结果也确定。

搜索与键盘导航

Cmd + K，标签秒级直达

无论开了多少标签，一个快捷键唤起搜索，模糊匹配标题与网址，回车即跳转。列表里还能用 j / k 上下移动、x 关闭、回车跳转，全程不用碰鼠标。

个性化配置

按你的习惯，精调每一处细节

设置页按「界面 / AI 服务 / 分组 / 自动整理 / 权限与数据」五类划分。API Key 只存在 chrome.storage.local，除了你自己配置的 AI 端点，数据不发往任何地方。

  • 界面形态 — 侧边栏或页面浮球，按你用不用原生垂直标签栏来选
  • AI 端点 — 接入 DeepSeek、OpenAI 等 OpenAI 兼容端点
  • 分组规则 — 命中规则的标签直接归组，完全不发给 AI
  • 自动整理 — 休眠空闲时长、自动归档天数，按需释放内存与注意力
  • 可选权限 — 历史、书签、最近关闭，用到才申请，随时可收回

安装与配置

当前为开发者加载方式，暂未上架 Chrome 应用商店。

  1. 1

    克隆仓库

    git clone git@github.com:Michaelooo/chrome-side-tabs.git
  2. 2

    安装依赖并构建

    pnpm install && pnpm build
  3. 3

    加载到 Chrome

    打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择项目根目录下的 dist/ 文件夹。

  4. 4

    个性化配置（可选）

    右键扩展图标 →「选项」进入设置页。先在「界面」里选形态：用 Chrome 原生垂直标签栏就选页面浮球，还在用水平标签栏就选侧边栏。再到「AI 服务」填入接口与模型。不填 API Key 则回退到按主域名与标题词重叠的本地聚类。
