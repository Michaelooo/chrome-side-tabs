# Side Tabs

Chrome 侧边栏标签管理扩展，基于 Manifest V3 + Side Panel API，内置可对话的 AI 标签助手。

介绍网站：https://michaelooo.github.io/chrome-side-tabs/

## 功能

### 标签列表

- **纵向标签列表** — 在浏览器侧边栏显示所有标签，替代顶部水平标签栏
- **AI 智能分组** — 接入 OpenAI 兼容端点（DeepSeek、OpenAI 等），按语义自动归类
  - 规则先行：自定义规则命中的标签直接归组，完全不发给 AI，省 token 且结果确定
  - 增量分组：只把没见过的标签送给 AI，已有判断从缓存复用（按住 Shift 点击可忽略缓存重算）
  - 本地兜底：AI 不可用时按「主域名 + 标题词重叠」聚类，比纯域名分组更准
- **来源链路** — 记录 `openerTabId`，按「这个标签是从哪儿点开的」串成树，支持折叠和整条链路关闭
- **键盘导航** — `j`/`k` 上下移动、`x` 关闭、`Enter` 跳转，输入框内不接管
- **重复标签合并** — 同 URL 的标签显示 `×N` 角标，点击合并
- **就地静音** — 有声音的标签直接在列表里静音，不用先跳过去找
- **专注模式** — 锁定一个分组，其余标签自动折叠并休眠
- **搜索** — `Cmd/Ctrl + K` 全局快捷键

### AI 标签助手

侧栏右下角浮球，点开是对话浮层。它能看到所有窗口标签的标题、域名、闲置时长、分组归属、重复情况和来源链路。

- **问答 + 操作一体** — 问「哪些标签在摸鱼」会列出判断和理由并高亮，底下跟操作按钮
- **读页面正文** — 「总结一下这个页面」「这几个文档讲的是一回事吗」，读的是真实内容不是标题
- **可执行的操作** — 归档 / 关闭 / 休眠 / 重载 / 固定 / 静音 / 分组 / 跳转 / 移到新窗口 / 打开网页 / 导出书签 / 恢复关闭的标签
- **整页截图** — 自动识别真正在滚动的元素（含 SPA 的内部滚动容器），逐屏滚动拼接成长图，超出画布上限自动降采样
- **检索历史与书签** — 需要时自动申请权限，查完再回答
- **对话历史** — 自动保存，可新建对话、加载历史继续聊；自动清理最近 20 个 / 30 天内 / 每个会话 60 条
- **安全边界** — 只读操作直接执行，会改动标签的操作一律先预览再等确认，关闭类标红

### 归档与恢复

- **归档抽屉** — 关掉但不丢。标签右键、分组标题、智能清理、性能页都能归档，可搜索、批量恢复、导出 Markdown
- **自动归档** — 超过设定天数未访问的标签自动收进归档并关闭
- **刚关闭** — 基于 `chrome.sessions` 找回误关的标签（归档管有意关的，这里管手滑关的）
- **会话管理** — 保存/恢复整套标签布局
- **智能清理** — AI 判断哪些标签可以清理，默认动作是归档而非关闭
- **标签休眠** — 自动休眠长时间未活动的标签，释放内存

### 性能页

独立页面（侧栏底部闪电图标进入），按需扫描，**不扫描时常驻开销为 0**。

- 一次性注入探针读取 JS 堆、DOM 节点数、图片解码位图、资源体积、iframe 数
- 首屏展示探针自身开销（平均每标签占用主线程多少毫秒），代价摊开给你看
- 重量分与浪费分排序，按分组、按共用渲染进程的站点分别聚合
- 注意力账单：打开后再没回访过的标签数、平均闲置时长、标签黑洞站点
- 已休眠标签自动跳过，避免注入把它唤醒

### 其他

- 深色 / 浅色主题
- 配置备份与恢复（导出 JSON，API Key 可选是否包含；导入采用合并策略，不冲掉现有数据）

## 权限说明

**安装即需要**：

| 权限 | 用途 |
|---|---|
| `tabs` `tabGroups` | 读取和操作标签、同步原生标签组 |
| `storage` | 本地保存设置、归档、对话历史 |
| `sidePanel` `commands` `alarms` `favicon` | 侧边栏、快捷键、定时任务、图标 |
| `scripting` + `<all_urls>` | 性能探针、整页截图、读取页面正文 |

**可选权限**（安装时不索取，用到才申请，可随时在设置页收回）：

| 权限 | 用途 |
|---|---|
| `history` | 在浏览历史里检索 |
| `bookmarks` | 检索书签、导出标签为书签文件夹 |
| `sessions` | 查看和恢复最近关闭的标签 |

所有数据仅存在浏览器本地，API Key 存于 `chrome.storage.local`，不会上传到除你自己配置的 AI 端点之外的任何地方。

## 技术栈

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- CRXJS Vite Plugin（Chrome Extension HMR）
- Chrome Manifest V3 + Side Panel API

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式（支持 HMR）
pnpm dev

# 构建
pnpm build
```

### 加载扩展

1. 打开 `chrome://extensions`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"，选择 `dist` 目录

### 首次配置

1. 点击扩展图标打开侧边栏
2. 点击"AI 分组"按钮或进入扩展选项页
3. 填写 API 地址（如 `https://api.deepseek.com`）、API Key、模型名称
4. 可在选项页查看系统提示词、添加自定义分组规则、配置自动归档

### 侧边栏位置

前往 `chrome://settings/appearance`，在"侧边栏"选项中选择"在左侧显示"。

## 已知限制

- **分屏**：Chrome 未开放创建拆分视图的 API，扩展只能读取分屏状态。助手被问到时会给出手动操作说明
- **整页截图**：虚拟滚动列表（只渲染可视区域的信息流）无法截全；最多 20 屏
- **来源链路**：只对本次浏览器会话内新开的标签生效，`openerTabId` 仅在标签创建时可得
- **对话历史**：截图不入历史（dataURL 体积过大，会撑爆存储配额）
